# 映间 · 动画作品人物关系分析与可视化

基于 Spring Boot、Vue、MySQL 与 Neo4j 的本科毕业设计。核心为角色关系建模、证据展示、跨作品联系分析与图谱可视化，片单、观看画像和可解释推荐为扩展功能。

## 功能入口

| 入口 | 功能 |
|---|---|
| `/anime` | 统一搜索、作品详情、角色图谱和演职员 |
| `/connections` | 两端角色的最短联系、多条路径及证据 |
| `/library` | 关联 Bangumi 公开账号，读取片单 |
| `/preferences` | 观看画像、声优/公司统计、推荐与反馈 |
| `/compare` | 共同人员、声优、角色和标签对比 |

作品支持保存、更新、删除本地资料、角色编辑、多语言名称与头像取景。本地与在线使用同一作品流程。剧情关系和配音联系分别标注，不按共同出场推测剧情关系，剧透默认隐藏。

## 本机运行

首次仅在没有 `.env` 时运行 `scripts/Initialize-Local.ps1`，在 `frontend` 执行 `npm ci`。项目根目录启动：

```powershell
.\Start-Project.cmd -JavaHome 'C:\Program Files\Java\jdk-23' -MySqlHome 'D:\Tools\mysql-9.3.0-winx64'
```

访问 [映间](http://127.0.0.1:5173/anime)。前端 5173、后端 8080、MySQL 3307、Neo4j Bolt 7687。使用 `Stop-Project.cmd` 停止应用，数据库默认保留。前提、索引和容器方案见[运行说明](docs/演示与运行说明.md)。

```powershell
# 常规测试、契约、文档、类型检查与前端构建
.\scripts\Test-Project.ps1 -JavaHome 'C:\Program Files\Java\jdk-23'
# 显式运行本机两库集成；需要现有数据库和真实公开样本
.\scripts\Test-Project.ps1 -JavaHome 'C:\Program Files\Java\jdk-23' -DatabaseIntegration
```
