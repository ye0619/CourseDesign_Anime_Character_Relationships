# 映间 · 动画角色关系与观看偏好

基于 Spring Boot、Vue、MySQL 与 Neo4j 的动画网站。围绕两件事：探索动画里的真实角色关系；关联 Bangumi 片单，查看观看画像和有解释的推荐。

**已移除“精选”产品及固定20部作品限制。** 本地与在线只代表来源，使用同一搜索、详情、角色图谱和演职员名单。已有数据、用户配置和 Bangumi 关联保留。

## 使用入口

- [探索动画与角色关系](http://127.0.0.1:5173/anime)：搜索任意 Bangumi 动画，优先读取可用本地资料，缺失时在线补全。
- [我的片单](http://127.0.0.1:5173/library)：公开账号关联及收藏读取，无需本地注册。
- [观看画像与推荐](http://127.0.0.1:5173/preferences)：观看状态、评分、标签、制作人员/声优统计及有依据的推荐。

作品详情可保存本地、更新数据、确认后删除本地作品、打开2.5D角色关系与本地编辑、查看角色及制作人员/配音列表。无真实关系资料时如实提示，不根据共同出场造线。剧透关系默认隐藏。旧精选地址兼容跳转到统一搜索，旧本地作品地址兼容跳转到统一详情。

## 本机启动

在项目根目录用 PowerShell 执行：

```powershell
.\Start-Project.cmd -JavaHome 'C:\Program Files\Java\jdk-23' -MySqlHome 'D:\Tools\mysql-9.3.0-winx64'
```

访问 [映间](http://127.0.0.1:5173/anime)。默认绑定回环地址；保存操作限定本机并保留CSRF校验。Flyway保留V9 saved_anime；本轮仅新增Neo4j V004本地扩展约束，不删除历史表或官方图数据。

首次配置：仅在没有.env时运行 `scripts/Initialize-Local.ps1`，在frontend执行 `npm ci`。Java目标21、本机JDK23，Node24；Spring Boot3.5.16、Vue3.5.44及现有锁定依赖保留。数据库默认MySQL3307、Neo4j7687，后端8080、前端5173。不要覆盖已有.env。

```powershell
# 测试、接口契约、类型检查与前端构建
.\scripts\Test-Project.ps1 -JavaHome 'C:\Program Files\Java\jdk-23'
# 实际两库集成测试
.\scripts\Test-Project.ps1 -JavaHome 'C:\Program Files\Java\jdk-23' -DatabaseIntegration
# 真实保存/更新公开作品373267；会保留正常作品数据
.\scripts\Verify-UnifiedWorks.ps1
# 停止应用，保留两库及数据
.\Stop-Project.cmd
```

测试日志与恢复源码快照放在私有.local目录。不公开.env、Token、Cookie、私人片单或数据库目录。普通浏览不会自动永久收录；主动保存与临时缓存区分。

## 角色关系来源

官方资料只接入Bangumi公开服务及官方Archive；用户手动补充单独标注为本地添加。新索引从官方ZIP流式构建，校验散列、仅索引crt关系，按作品范围查询，不在每次打开作品时下载或扫描全量归档。未来数据源只留简单Provider接口。

本机已有10月13日快照的索引；新环境需使用官方ZIP及其实际SHA256构建，详见[来源与导入说明](docs/数据来源及角色关系获取说明.md)。未导入索引或来源未收录时，角色名册仍正常展示。Archive是角色全局关联，不代表本季剧情时点。

## 2026-10-24 新增功能

报告v4新增声优实际配音角色、动画制作公司和搁置/抛弃分析，需在画像页面重新生成。作品图谱可添加本地角色、虚构组织、多成员和自定义关系，支持来源筛选、组织折叠、平滑聚焦及2.5D头像卡片。资料保存在当前服务实例共享的Neo4j，不上传Bangumi；每次修改自动备份，并支持JSON导出恢复。新增Neo4j V004约束，MySQL仍V9，原有资料保留。

完整交付、模型、文件、验收及限制见[10.24升级记录](docs/画像与本地图谱升级10.24.md)。本地编辑及官方同步保留复验：`scripts/Verify-LocalGraph.ps1 -RefreshOfficial`。按后续明确指令，增加本地作品删除入口，并精确清理测试动画A/B/C/D；删除范围及备份见[本地作品删除记录](docs/本地作品删除与测试数据清理10.24.md)。
