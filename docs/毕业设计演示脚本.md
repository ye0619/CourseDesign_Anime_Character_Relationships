# 本轮毕业设计演示脚本

先启动项目并确认READY。演示使用允许展示的公开样本和自己的关联账号；候选、资料补充与世界观任务有界执行。网络不可用时说明当前显示的是已存快照，不能伪装在线实时数据。

| 时间 | 操作 | 说明与核对点 |
|---|---|---|
| 0—1分钟 | 探索作品输入“孤独”，用键盘选中候选 | 下拉显示中文名、原名、年份和不同季；不需要导入本地 |
| 1—3分钟 | 打开328609角色关系，缩放、点边、选角色 | 可见标签避开头像；选中关系全文、来源及方向可核对；头像原图与本机取景可切换 |
| 3—5分钟 | 打开世界观，进入孤独摇滚或巨人连续性 | 作品/季、组织、关系和剧透筛选；全局与本季范围不同；展示第二来源成员证据及候选身份状态 |
| 5—6分钟 | 展开关系分析，选择两位角色 | 连接度按不同邻居去重；有界最短路径；关系类型/明确组织成员分布；仅说明当前已收录样本 |
| 6—7分钟 | 对比328609与214265，展开共同人员 | 稳定ID交集、两侧职务、分栏完整性；本地路径另有覆盖说明 |
| 7—9分钟 | 观看偏好生成已有资料报告，再查看推荐 | 报告作品去重与评分样本；不足资料显式提示；推荐依据、冷启动、不感兴趣与撤销 |
| 9—10分钟 | 打开社区观察和实验/验收记录 | 社区样本清单与采集时间；说明实际测试、实验结果和仍受外部条件限制的增强项 |

准备事项：提前对需要演示的作品显式补充公共资料；世界观样本首次生成需读取远端；推荐候选需在已关联账号的推荐区主动更新。个人报告可先生成已有资料版本，再按需继续补充，不必在答辩现场等待大量作品资料。

本轮推荐未启用协同过滤和候选人员权重；百科正文自动抽取与30张头像的全部人工审核是否完成，应以实施记录与样本清单为准。演示时如实说明，不能将计划目标直接读作完成情况。
