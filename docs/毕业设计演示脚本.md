# 毕业设计演示脚本

基线日期：2026-10-24。主线为数据、关系模型、约束寻路与证据，画像推荐为扩展。先准备公开资料、固定端点并确认 READY。

| 时间 | 操作 | 说明 |
|---|---|---|
| 0—1 分钟 | 搜索“孤独”并进入统一详情 | 名称/年份/稳定 UID、本地优先 |
| 1—3 分钟 | 图谱选择、筛选、证据和关系分析 | 类型、方向、剧透、全局范围，不造线 |
| 3—4 分钟 | 角色名称/头像编辑及恢复 | 独立修改、共享范围、备份与冲突 |
| 4—7 分钟 | 联系页展示 2 步、6 步、多路径和无结果 | 两类节点、跨作配音、固定版本、最短证明及预算 |
| 7—8 分钟 | 作品对比 | 人员/声优/角色交集，稳定身份与去重 |
| 8—9 分钟 | 已生成画像和推荐 | 覆盖、未评分、公司职责、理由与冷启动 |
| 9—10 分钟 | 模型、实验和测试材料 | 已有证据与人工/异机/规模限制 |
