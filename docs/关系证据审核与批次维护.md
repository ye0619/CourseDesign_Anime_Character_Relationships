# 关系证据审核与批次维护

同步日期：2026-10-24。流程为预览、核对身份/原文/范围、提交、查看批次、停用或撤回。默认关闭，ADMIN 与 CSRF 必须有效。

## 操作

使用 scripts/Invoke-EvidenceMaintenance.ps1，支持 Preview、Apply、List、Disable、Revoke：

```powershell
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action Preview -Path .\data\samples\reviewed-evidence-example.json
# 核对后填实际返回的 previewId
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action Apply -PreviewId '<实际previewId>'
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action List
```

[示例包](../data/samples/reviewed-evidence-example.json)仅说明格式，不照抄其时间/原文/修订作新依据。字段见[接口契约](接口契约.yaml)。工具限回环地址，不自动开启维护或创建管理员。

## 输入与事务

单包 512KB、最多 200 条。端点需现有启用角色及当前世界观名册，按稳定 UID，不按名称、不自动审核身份。来源需链接、修订、字段、原文、许可与署名。

仅 GLOBAL 或 SUBJECT_EXPLICIT，明确作品须双方出场且为成员作品；不从全局推本季。共享字典处理类型/方向，无向端点规范化。多证据不放大事实数，冲突并列不投票定真伪。

预览不写图，绑定账号，10 分钟过期、最多 32 份、重启失效。提交仅 previewId，重新核对摘要/名册/版本，变化 409。批次、证据和断言同 Neo4j 事务；同批同内容幂等，异内容拒绝。SQL 附加日志不是跨库原子保证。

停用批次保留其他有效批次的共享证明，最后一份停用后重放不能复活。撤回断言隐藏整条关系，刷新/新批次不能隐式恢复；新修订仍需审核。

REVIEWED 观察代际保护审核证据，图版本含名册和证据修订，画布/分析固定同一版。旧冻结授权只用于维护，不限制普通作品搜索保存。

## 验证

scripts/Test-EvidenceMaintenance.ps1 显式测事务、共享、严格范围、冲突、停用和撤回；需要现有真实作品，按精确范围清理。Verify-EvidenceRuntime.mjs 检查运行边界。事务测试不替代人工事实或真实管理员浏览器验收，结果见[测试报告](测试报告.md)。
