# 关系证据审核与批次维护

本轮补齐T08的关系证据维护链路：**上传预览 → 核对原文/身份/范围 → 提交预览 → 查看批次 → 停用批次或撤回断言**。仅供已有管理员维护流程使用，不增加普通用户的匿名写入入口，也不恢复旧后台导航。

## 权限与使用方式

现有`app.admin.enabled`维护开关默认关闭，关闭时连管理员也不能访问。启用后仍须有效ADMIN Session和CSRF；不得以Bangumi公开账号关联代替本机维护权限。此次没有修改本机维护开关。

在已由维护人员启用并配置凭据的本地环境中，可使用PowerShell 7：

```powershell
# 第一步仅预览，输出角色名称/编号、原文、来源位置、修订、许可及新增/复用/阻塞项。
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action Preview -Path .\data\samples\reviewed-evidence-example.json

# 核对后，将上一步实际返回的previewId填入；此命令不重新上传可变的文件。
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action Apply -PreviewId '<返回的previewId>'

.\scripts\Invoke-EvidenceMaintenance.ps1 -Action List
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action Disable -BatchId '<批次编号>' -Reason '经核对停用本批资料'
.\scripts\Invoke-EvidenceMaintenance.ps1 -Action Revoke -AssertionUid '<断言uid>' -Reason '该关系依据已撤回'
```

工具从既有本机配置中读取维护凭据，会话与CSRF仅保存在内存中，结束时尝试退出登录；仅接受回环地址。不会自动启用维护开关、创建管理员或持久化登录会话。默认关闭环境返回拒绝属于正常边界，不是需要去绕过的错误。

[输入示例](../data/samples/reviewed-evidence-example.json)将已有的后藤一里所属团体人工核验事实转为新包格式；日期沿用已存证据的实际取得时间，版本为8606350。它不是新增外站覆盖样本，也没有在此次验证中再次提交到正式世界观。实际新资料须填写自己的获取时间、修订、字段位置与原文，不能照抄示例。

## 导入规则

- 单包最大512KB、最多200条事实。未知字段、无来源修订/字段/原文/署名、非布尔状态、未知关系类型、未审核候选、按名称推测身份及不符合来源站点的URL均拒绝。
- 不创建角色，不自动合并姓名，不自动提升`external_identity`候选。端点须为现有启用的稳定角色UID，并处于当前世界观的已发布名册。
- 只接受`GLOBAL`或`SUBJECT_EXPLICIT`。全局不填作品；明确作品范围必须填写世界观成员作品，且两端均在这些作品的名册内。来源没有明确季范围时不得填本季。
- 关系类型和方向使用共享字典。无方向关系规范化端点，有方向关系保留方向；相反方向、不同关系类型与不同明确范围不合并。不同来源的冲突断言并列保留，不以来源数量投票认定真伪。
- 相同断言、来源URL、修订、原文及许可等组成稳定证据身份；相同证明跨批复用，同URL不同修订可分别展示。前端用证据UID作为列表标识，避免同URL版本互相覆盖。

## 预览与事务

预览不写入图谱，缓存绑定维护账号，10分钟过期，最多32个；服务重启后须重新预览。提交仅接收previewId，不能换入未经本次预览的新文件。

预览记录规范化包摘要和数据库基线摘要。提交时在图数据库内锁定涉及的世界观，重新验证名册、代际、证据修订及批次状态；不一致返回409且不发布新批次。不同进程的维护写入使用相同锁顺序，已有证据在提交阶段再次检查撤回状态。

`EvidenceImportBatch`、关系断言、证据及关联在同一Neo4j事务提交。批次保存规范化资料、内容摘要、维护账号、时间及来源版本，可追溯。相同批次同内容重复提交幂等，不同内容占用同编号被拒绝。无需MySQL/Neo4j跨库原子事务；现有MySQL操作日志为附加审计，若日志服务暂不可用，图内批次/撤回记录仍在，后台记录告警。

## 停用、撤回与刷新

批次停用后，其他有效批次仍使用的共享证明保留；最后一批支持停用时，该证据版本形成停用标记。原批次不能重新提交，换批次重放同一证明也不会恢复它。后续取得新的修订与独立人工审核，属于新的证据版本，而不是旧证明自动复活。

撤回断言则使整个关系不可见；任何来源补充、批次导入和`ON CREATE active=true`刷新都不能重新启用它。当前工具不提供隐式恢复操作。

已审核关系通过`OBSERVED_IN {generation:'REVIEWED'}`关联世界观，公共名册换代后仍有效，但继续受当前名册、范围、剧透及停用状态过滤。维护更新所有受影响世界观的证据修订号；网络版本包含名册代际和证据修订。读取期间版本变化会有限重试，分析接口可要求与画布相同版本，防止混用更新前后的统计。
