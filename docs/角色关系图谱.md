# 角色关系图谱与编辑

同步日期：2026-10-24。统一详情 `/explore/anime/:id`，全屏 `/explore/anime/:id/network`；演职员和配音采用名单，不混作剧情连线。

## 图谱

读取 Neo4j 与官方归档索引；缺关系仍能浏览角色与缺失原因。默认隐藏剧透，不按共同出场造线，保留类型、方向、结束状态与来源证据。

Cytoscape/fCoSE 提供头像、搜索、筛选、拖拽、缩放、聚焦、重新布局和 PNG。选择改变强调和镜头，主动布局才重算。焦点/邻居/背景有空间层次，属于二维/2.5D，不是真正 3D。

连接度按不同邻居去重，不把同一角色对多条关系计成多人。连通分量仅说明已收录图连接，不称剧情社群；路径与统计只代表当前范围。

## 编辑存储

| 类型 | 存储及行为 |
|---|---|
| 来源角色修改 | SQL character_edit；独立覆盖名称、显示名、头像、性别、简介、备注、取景；不改原 UID/关系，可逐字段或全部恢复 |
| 本地工作区 | Neo4j 工作区；UUID 角色、虚构组织、成员与自定义关系，不上传 Bangumi、不按姓名补身份 |

数据属于当前服务实例共享，并非浏览器私人草稿。来源更新保护人工修改，来源与本地声明可筛选，组织可折叠。

工作区格式 2，含多语言与取景；格式 1 可显式转换，旧客户端不得覆盖已有格式 2。上限 300 节点/800 关系，版本冲突 409。来源角色修改使用另一种格式 1，不能混用编号或导出文件。

名称含 id/text/locale/kind/source/reviewStatus，可指定显示名，中文优先；原语言需明确，未知 und。头像保存模式/焦点/缩放和内容指纹，不破坏原图；本作优先通用再回退自动，内容更换使旧取景失效。名册、卡片、图谱与路径共用计算。

自动保留最近 20 份备份，分别支持 JSON 导出恢复；恢复带当前版本，工作区恢复不写来源角色全局修改。

复验为 `scripts/Verify-LocalGraph.ps1 -RefreshOfficial` 与 `scripts/Verify-Connections.ps1`，需要现有样本，会产生临时修改与备份。人工事实、真实设备全矩阵和大规模帧率未完成，见[测试报告](测试报告.md)。跨作品规则见[角色联系探索](角色联系探索.md)。
