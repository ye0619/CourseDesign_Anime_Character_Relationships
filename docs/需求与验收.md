# 需求与验收

基线日期：2026-10-24。请求字段由[接口契约](接口契约.yaml)维护，实际结果见[测试报告](测试报告.md)。

## 当前范围

面向动画资料浏览者，提供角色关系与跨作品联系分析。普通访问无需本地注册；公开账号关联仅用于本浏览器作用域的片单与报告，不证明账号所有权。维护使用显式开启的 ADMIN 会话。

| 模块 | 当前能力 | 验收重点 |
|---|---|---|
| 统一作品 | 搜索、详情、保存、更新、删除本地资料 | 同 UID 同入口；本地优先；失败保留旧资料；查看任务最终状态 |
| 角色图谱 | 关系、筛选、聚焦、证据与导出 | 不造线；关系去重；方向、剧透与范围明确 |
| 角色编辑 | 独立修改层、本地工作区、多语言、头像 | 来源刷新保护修改；409 冲突；备份恢复与共享范围 |
| 联系探索 | 角色/声优节点，配音/剧情事实，最短与多路径 | 固定版本；跨作品配音；无重复 UID；最短证明与停止原因 |
| 演职员/对比 | 职务、声优角色、共同人员与标签 | 稳定身份、作品去重，制作与剧情分开 |
| 片单/报告 | 五状态、画像、人员/公司/声优、搁置抛弃分析 | 未评分不计 0；覆盖与偏好分开；账号版本隔离 |
| 推荐 | 热门、内容、混合，理由、排除与撤销 | 全收藏状态排除；冷启动；真实依据作品 |
| 扩展图分析 | 世界观、制作网络、关系统计、有界路径 | 当前范围统计；全局事实不当作本季事实 |
| 维护 | 身份审核/改绑/别名，证据批次/撤回 | 默认关闭；ADMIN、CSRF、版本、审计 |
| 工程 | 启停、迁移、契约、测试、构建、恢复 | 模拟/数据库/浏览器/人工证据分别记录 |

## 固定口径

实体用稳定 UID，姓名只用于显示检索。同名不合并，本地声明不伪装来源。剧情关系和配音联系语义不同，共同出场不推导朋友、同伴或亲属。

已移除精选产品、固定 20 部限制及报告交集。旧 `/curated` 只跳转 `/anime`。冻结维护授权资源仅用于旧证据权限，不限制普通作品搜索保存。

统计保留分母、覆盖和来源时间；发行年不是观看年，接触次数不直接等同喜好。未找到路径只代表当前范围；完全穷尽、截断、超时与取消分别表达。

## 待完成与验证目标

本地列表/详情 P95 目标 1 秒，邻居/共同项/统计 2 秒，有界路径 3 秒。至少 30 次同条件采样，区分冷/热读、可达/不可达和外站延迟。阶段小样本不能推广为所有接口保证。

| 待完成 | 所需证据 |
|---|---|
| 独立剧情事实核验 | 代表作品、人工标注、抽样正确率与错误案例 |
| 寻路基线对照 | 相同约束、端点与预算的正确性、耗时、状态数和中断率 |
| 干净环境部署 | 空库初始化、公开资料导入、启动和重启后完整链路 |
| 离线演示 | 实际断网检查，区分已存资料与外站媒体 |
| 规模与设备 | 高度/稠密图、并发/内存、真实手机与系统缩放 |
| 论文答辩 | 需求、架构、模型、算法、实验与实际演示一致 |

真正 3D、人员推荐特征、多用户协同过滤是未实现增强项。
