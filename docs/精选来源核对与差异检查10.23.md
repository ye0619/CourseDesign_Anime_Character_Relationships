# 精选来源核对与差异检查（2026-10-23）

对应G04/G05/G23/G26，契约0.18.0。当前结果是可运行的来源核对功能，尚不是任意新包的管理员预览、发布流程，也不代表来源当前名单或剧情事实完整。

## 已核对的资料

对20部精选的60份本地Bangumi响应，按原采集器规则重建制作职务、角色出场和明确作品内配音，再逐条对照标准包。采用稳定编号及关系身份，未按名称猜测合并。

- 标准包4,019个实体的UID集合与采用的来源身份一致。
- 7,488条关系输入按稳定身份去重后为7,486条；其中2条重复输入不会在图中重复建边。
- 制作响应中排除297条非自然人记录；配音不推断语种。
- 60次请求有9次复用缓存。获取时间未知时保留未知，缓存写入时间单列，不冒充来源获取时间。

归档文件SHA256、请求来源和时间、排除/重复计数及预期关系身份存于data/curated/local-library.archive.v1.json。清单和归档随JAR发布，启动核对定义版本、分组、缓存时间语义、端点与稳定关系身份；不依赖开发机原始文件目录。运行时返回归档字节版本，验证源码、JAR和实际HTTP版本一致。

本地响应与标准包一致不能证明历史时间戳经过认证，也不能证明上游内容永不变化。该归档只保存事实字段和摘要，不包含完整网页或外站图片；原始响应和标准包仍在本机数据目录，未打入公开源码制品包。

## 页面与接口

精选卡片新增“核对来源、缺项与更新差异”，首次展开才加载组件和请求GET /api/v1/curated/{subjectId}/coverage。初始20卡不会额外发起20次核对请求。支持失败提示、重试及折叠时释放请求，手机模拟视口可以阅读。

每组显示输入、采用、排除、重复和冻结预期记录；当前图中按稳定关系UID核对：
缺失、已停用、端点或明确作品出场不可用、身份冲突、重复关系ID、来源字段差异、人工字段保护和附加有效记录。完整计数保留，差异例子每组最多10条；部分状态可重叠，不应相加当作总数。

来源新鲜度只解释已知获取时间是否在6小时内；缓存获取时间未知时为NOT_VERIFIED。当前上游名单完整性继续标NOT_VERIFIED，不因本地记录齐全而改为COMPLETE。附加记录保留，页面不写入图库、不请求外站，也不返回可提交的导入令牌。多次读取不是跨查询的原子发布快照。

## 实际验收

新版Release通过20部、60分组HTTP核对，共找到7,486条冻结预期关系。该次缺失、停用、来源字段差异、人工保护差异、身份冲突、重复ID及附加记录计数均为0。这些是该次图库状态，不推断未来没有缺项。

实际Neo4j夹具反复导入同一人员和职务关系后仍只有一条边；人工名称、人工职务和停用状态保留。测试仅使用随机fixture端点，结束精确清理，未修改真实作品记录。

浏览器实测桌面首次展开只请求一个核对接口；390px模拟下，缓存作品显示未知获取时间与独立缓存写入时间；受控接口失败后重试恢复，页面无横向溢出、无修改请求。不是物理断网、真实手机或独立人工验收。

本轮122项后端（含6项实际数据库）、86项前端、来源归档4项测试及候选安全检查通过，0失败、0跳过。热读各30次：精选列表P95 240ms、来源核对58ms、详情10ms、角色图28ms；不是并发或冷启动测量。
