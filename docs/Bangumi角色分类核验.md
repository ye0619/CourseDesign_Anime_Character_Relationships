# Bangumi角色分类与角色关系核验

核验日期：2026-10-17。下文记录初次来源核验；后续已按用户要求完成分类改造、官方快照接入和布局更新，实际结果见[角色关系图谱](./角色关系图谱.md)。

## 结论

Bangumi网站已有角色—角色关联；官方共享配置person_relations.yml中define.types.character当前包含28个有效类别。项目现有五类为早期自行简化，不能视为Bangumi完整分类。此前只核验作品角色API，对角色互相关联能力的调查不完整。

字典声明的反向配对：改编/原型、进化/前身、主人/侍从、饲主/宠物、老师/学生、上司/下属；单恋标记skip_vice_versa。不能把未声明反向编号的类别一律当作无方向，例如成员和驾驶员仍有语义方向。

官网公告将关联方向定义为：被关联角色相对于当前角色具有所选身份。实际芙莉莲页的老师指向弗兰梅、学生指向菲伦，说明应保留页面主体、关联对象和原始类别，再显式转换项目的边方向。网站还支持剧透及关系已结束标记，不能只存关系名称。

## 不同层次不能混用

1. CharacterType：1角色、2机体、3舰船、4组织，是实体种类。
2. 作品内出场定位：作品角色接口的relation，例如主角、配角、闲角等；关联的是角色与作品。
3. 角色间关系：本次核实的28类，关联两个角色实体。

本地已缓存的作品400602样本有91个角色条目，type均为1，出场定位为6主角、56配角、29闲角。此为采集时快照，不保证永远与官网实时数据相同。

## 来源获取边界及后续设计

公开v0 schema已核对，角色端点包括详情、关联作品、关联现实人物等，未列出角色—角色关系读取端点。网站公开角色页确实展示关联；匿名访问关联编辑页要求登录，本次未登录或修改。官网有数据不等于当前作品角色API会返回这些数据。

后续接入已核实：[官方Archive](https://github.com/bangumi/Archive)的person-relations.jsonlines提供角色关联，character.jsonlines提供原始Wiki及简体中文名。已使用2026-10-13快照，提取现有933角色的688个明确中文名及983条作品限定关联，通过标准导入器写入，重复导入无重复边。老师/学生方向及单恋的单向规则经实际角色页与记录对照核验。

Bangumi角色关系可能跨漫画、动画和游戏等作品存在。本项目只向两端都有出场记录的作品投影，并明确提示这不代表当前动画季的剧情时点；保留来源、剧透和结束状态，不把共同出场自动推断为朋友或同伴。

界面建议将实体种类作为节点分类，将主角/配角等作为作品内筛选，将28类作为边分类；可按上方整理分组折叠展示，保留具体关系名称和方向。
