# 001：项目 Java 选择与本机数据库

- 初次决策：2026-10-16
- 更正说明：2026-10-24
- 状态：采用

默认 Java 曾是 8，因此项目使用现有 JDK 23，保留 Java 21 编译目标。脚本只改项目进程，不改系统默认 Java；构建使用 Maven Wrapper。

早期数据库待启动，后续已完成专用 MySQL 9.3.0、便携 Neo4j 5.26.16 的迁移、运行和同机恢复。Compose 仍只有静态检查，这是对早期状态的更正。

MySQL 使用项目数据目录，Neo4j 使用专用 Java 21 运行时，与应用 JDK 分别选择。Flyway/MySQL 9.3 有兼容提示，本机结果不能推广其他组合。Wrapper 既有 Windows 中文目录/空值修正重新生成时须复验。
