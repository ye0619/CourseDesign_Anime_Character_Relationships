# 001：复用本机JDK23，保留Java21编译目标

- 日期：2026-10-16
- 状态：采用

默认Java命令指向Java8；本机已经安装JDK23。Spring Boot3.5官方允许Java23，因此项目使用现有JDK23执行构建，通过Maven的release21生成Java21目标字节码。

启动和测试脚本只设置当前进程JAVA_HOME，不修改系统默认Java，不安装全局JDK。允许通过脚本参数或项目.env指定JDK21—25。

本机没有Docker，也没有已监听的项目数据库。先完成工程、接口契约、前端和数据库不可用时的真实反馈；Compose准备完成后仍须在具备Docker的环境中验证两个数据库。S02在此之前保留“待验证”。不将内存模拟数据库当成Neo4j或MySQL验收通过。

Maven官方Wrapper3.3.4在当前Windows PowerShell对普通.m2目录读取Target[0]时可能遇到空数组，已仅增加空值保护，保留官方脚本其余流程及Apache许可。后续重新生成Wrapper时须保留或复验该兼容修正。
