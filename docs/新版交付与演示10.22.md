## 交付内容

执行`Build-Delivery.ps1`后，在本机`.local/deliveries/`生成新的交付目录、同名ZIP与SHA256校验文件，不覆盖旧版本；当前包的位置记录在`.local/delivery-manifest.json`。

交付目录包含当前源代码、可执行后端、前端dist、依赖锁文件、启动/停止/验证脚本、配置示例、接口契约、说明及公共样本JSON证据。它不包含`.env`、账号文件、`.local`、数据库目录、原始外站图片缓存、前端node_modules或本机运行时。

`delivery-manifest.json`列出每个文件的相对路径、字节数和SHA256，并记录完整检查结果。源码指纹与测试通过时不一致，或JAR/前端文件在构建后发生变化，会拒绝封存。文件被修改、漏列/多出文件、重复或不安全路径会使校验失败。原始ZIP可以直接校验，无需先解压到磁盘。

本轮包用于当前项目的源码及构建审阅。运行前需要PowerShell7、JDK21—25、Node24、前端依赖和外部MySQL/Neo4j配置；本轮运行验收使用当前电脑已有数据，不代表新电脑、空库或Docker已通过。

## 构建、校验与启动

```powershell
# 完整检查、JAR打包、生成交付目录与ZIP
.\scripts\Build-Delivery.ps1 -JavaHome 'C:\Program Files\Java\jdk-23'

# 校验原始ZIP；也可以校验未配置、未修改的交付目录
.\scripts\Verify-Delivery.ps1 -Path '<交付ZIP或目录>'

# 当前电脑切换到打包模式，安全停止会先核对进程归属和活动任务
.\scripts\Stop-Project.ps1
.\scripts\Start-Project.ps1 -Mode Release -SkipDatabases -JavaHome 'C:\Program Files\Java\jdk-23'
.\scripts\Verify-DeliveryRuntime.ps1
```

分发审阅时保留原始ZIP及校验文件。实际运行时解压到另一个工作目录，按`.env.example`配置自己的数据库和来源参数；已有`.env`不会被初始化脚本覆盖。前端依赖需要在`frontend`目录执行`npm ci`。当前电脑可继续使用原项目目录及现有私有配置，已封存的交付目录保持原样。

配置后目录会新增私有文件，因此完整性验证应针对原始ZIP或尚未配置的解压目录。私人配置、数据库和账号文件不属于可分发内容。外站封面与头像仍按来源读取，当前包没有附带原站图片缓存。
