# 身份审核、改绑与来源别名

同步日期：2026-10-24。入口 `/maintenance/identities`，维护默认关闭，启用后仍须 ADMIN 会话与 CSRF。公开账号关联不授予维护权限。

## 身份与版本

provider+实体类型+区分大小写来源编号唯一对应现有 UID，姓名不证明身份，不自动建目标。支持候选、补充、审核、改绑、驳回、撤回与新修订重开。

登记需白名单 HTTPS 来源、修订、许可、原文、目标和理由。TITLE_ONLY 仅标题不得审核，须补不同核验文字为 MANUAL 再审核。批量预览最多 30 条，串行登记、可暂停和逐条反馈，不自动发布。

待审核可补充/审核/驳回；待审核或已审核改绑后回到待审核，保留原映射。已审核可撤回并从公开读取隐藏；驳回/撤回须不同新修订与完整新原文显式重开，旧种子不能复活。

修改带版本，冲突 409。身份、版本、事件和 SQL 审计同事务，日志失败回滚；页面读取最近 100 条历史，库保留全部。

## 来源名称

名称保存语言/类型/规范化键、来源 URL/修订/许可/依据，绑定身份 ID、审核版本和目标。公开搜索仅用当前 REVIEWED 且版本目标一致的名称。替换保留前后快照；撤回/重开/改绑使旧名称失效，不能在重新审核时无新依据恢复旧目标别名。

身份映射不搬迁图关系、不改角色 UID、不把候选发布为剧情事实，改绑后须另核证据。维护不抓任意远端页面；历史候选不代表多源自动抽取完成。

`Test-IdentityReview.ps1`、`Verify-IdentityRuntime.ps1`、`Verify-ReviewedNamesRuntime.ps1` 位于 scripts，验证事务、并发、名称绑定及默认关闭。需要已有真实目标，临时记录精确清理；页面夹具不等于真实管理员全流程。见[测试报告](测试报告.md)，剧情证据见[证据维护](关系证据审核与批次维护.md)。
