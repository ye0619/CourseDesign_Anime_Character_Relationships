# 人员总体报告与资料复用（2026-10-23）

对应总计划G17，以及G10/G21/G23/G26的相关部分。实现不代表该任务的独立人工和实际账号验收已完成。

## 当前行为

偏好页的演职员报告提供“人员总体/按职务”和“全已看片单/已看与精选交集”。两种范围都以当前已同步且状态为已看的作品计算实际分母。片单截断时仅代表已同步范围，不固定写20或118。

人员总体使用稳定人员UID+作品ID去重；职务项使用人员UID+职务+作品ID去重。一个人兼任导演和编剧、或在同一作品配音多个角色，人员总体仍只算一部。同名不同UID不合并。总体中的职务筛选只筛出担任过该职务的人员，总体作品数仍跨职务去重；按职务视角可核对对应部数。

仅统计来源明确的自然人。公共名册中的组织或未知类型不会按自然人计数；本地标准包已排除来源组织。未知配音作品范围不加入本作配音统计，语种未知不会被推断为日语。未评分不计0分；少于3部已评分作品不提供校正评分，先验均分来自各自报告范围。

## 输入与覆盖

- 已看的精选成员使用Neo4j当前有效制作职务和明确本作配音。读取不会导入或请求外站，每作品每组最多读取5001条以检测上限，只纳入前5000条。
- 本地记录存在不等于来源已完整采集。本地各组标记NOT_VERIFIED；达到上限则为PARTIAL。未知来源获取时间不借用数据库更新时间填充。
- 其他作品使用已保存公共分页。完整性分为COMPLETE、PARTIAL、NOT_FETCHED、NOT_VERIFIED；新鲜度另分FRESH、STALE、NOT_VERIFIED。超过6小时或来源返回旧缓存不会抹掉已经采集完整的事实。
- 继续补充仅针对非精选作品的公共名册，每批最多100部、120秒。精选永久资料由维护流程更新。两个范围均从同一批输入生成，逐作品列明分组记录数、获取时间和输入版本。
- 每种排名最多返回500项，同时返回实际项数。五部真实作品验收的自然人总体为1052项，核对了实际返回的500项及完整项数；不能称为1052项逐人手工核验。

## 保存与任务

版本为viewing-report/2，仍使用现有受用户绑定版本和片单时间保护的MySQL报告JSON。旧viewing-report/1可读取，新增字段为空，不凭空补出覆盖；页面引导重新生成。精选定义改变会提示旧报告版本不同，旧内容继续可读。

取消与发布使用同一任务锁；账号绑定或片单变化由当前状态检查和SQL条件写入共同阻止旧任务回写。生成失败保留旧报告。进度分母统一为本批补充作品数，不在完成时切换为全片单部数。

当前报告任务仍在进程内运行，未实现跨重启续跑。页面说明重启后需重新发起，已保存报告保留。这属于明确的中断语义，不是持久化任务恢复；G21完整统一仍未完成。
