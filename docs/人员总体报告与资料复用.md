# 观看画像、人员统计与资料复用

同步日期：2026-10-24。`/preferences` 使用 viewing-report/5，按全已看片单统计，已移除精选交集。旧报告兼容读取，需重新生成才能获得新增内容。

## 统计口径

观看状态、评分、标签、发行年、形式、声优、动画制作公司及搁置/抛弃使用 ECharts；公司可切数量/均分散点，表格可键盘下钻。发行年不是观看年，接触次数不是喜好。

人员总体按 UID+作品去重，职务项再加职务。兼多职或同作配多角色总体仍一部，同名不同 UID 不合并。未评分不计 0，少于 3 部已评分作品不提供校正评分。

声优展示实际配音角色和作品，不猜语言/版本。公司仅接受明确机构类型、职责为动画制作/アニメーション制作，发行/委员会/音乐制作/协力不混入。联合制作分别计入，每公司同作只一次。

## 资料与覆盖

复用已保存分页、本地图和历史公开名册，旧回退不能覆盖当前有效名称。完整性 COMPLETE/PARTIAL/NOT_FETCHED/NOT_VERIFIED 与新鲜度 FRESH/STALE/NOT_VERIFIED 分开；未知获取时间不填库更新时间，过期不抹掉已完整采集事实。

按作品标明来源、版本、时间、覆盖；排行上限与实际总项数分开，片单截断只代表已同步范围，缺公司资料显示未覆盖，不把有限公司数当全量。

报告绑定账号修订和片单版本；取消/换号/解绑阻止旧任务发布，失败保留旧报告。任务在进程内，重启后重新发起，已存报告保留，未实现续跑。报告、私人片单和关联不作为公开样本。
