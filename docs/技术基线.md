# 技术基线与项目结构

同步日期：2026-10-24。以下为仓库锁定选择，不声称当前最新；以 POM、package.json 和锁文件为准。

| 组件 | 固定版本/用途 |
|---|---|
| Java | 编译目标 21；本机 JDK 23 |
| Spring Boot / MyBatis Starter | 3.5.16 / 3.0.5 |
| Neo4j Java Driver | 6.1.0；直接 Driver/Cypher，不采用 Spring Data Neo4j |
| Maven | Wrapper 固定 3.9.16 |
| Node | >=24.15.0 且 <25 |
| Vue / Router / Pinia | 3.5.44 / 4.6.4 / 3.0.4 |
| Cytoscape / fCoSE | 3.34.4 / 2.2.0；关系布局 |
| ECharts / Element Plus | 6.1.0 / 2.14.7 |
| Vite / TypeScript / Vitest | 8.3.4 / 5.9.3 / 5.0.5 |
| 本机数据库 | MySQL 9.3.0；Neo4j 5.26.16 Community |
| Compose | mysql:8.4.7；neo4j:5.26.16-community；仅静态验证 |

Connector/J、Flyway、Security 沿用 Spring Boot 依赖管理。MySQL 9.3/Flyway 存在兼容提示，本机成功不代表所有组合均验证。

## 目录职责

| 位置 | 用途 |
|---|---|
| backend 的 explore | 统一作品、公共资料、缓存与保存 |
| charactergraph / localgraph / characteredit | 来源关系、本地工作区、来源角色独立修改 |
| connection | 投影、任务、不可变快照与 A* |
| graph / viewer | 通用图与世界观；片单、报告和推荐 |
| identity / auth / config | 身份/证据维护、权限、配置与迁移 |
| backend/src/main/resources/db/migration | SQL V1—V10 |
| backend/src/main/resources/neo4j | 图迁移 V001—V005 与演示 Cypher |
| frontend/src | 页面、组件、类型、交互与请求 |
| scripts | 运行、验证、来源处理、维护、恢复与交付 |
| data/fixtures | 回归夹具，不作为真实来源 |
| data/samples | 实验与回归样本，部分被自动化测试直接读取 |
| docs/实验数据 | 可分享的冻结实验及最近检查摘要 |
| .local / data/raw / data/index | 私有环境、日志、备份、数据库、来源与索引 |
