# 数据来源及角色关系获取说明

同步日期：2026-10-24。当前新增接入为 Bangumi 公开服务与官方 Archive，历史外站身份能力不代表已实现外站自动抽取。

| 来源 | 用途与边界 |
|---|---|
| [官方 API](https://bangumi.github.io/api/) | 搜索、详情、公开收藏；账号关联不证明所有权 |
| Bangumi next p1 | 演职员/配音分页，不是 v0 稳定契约，存在兼容风险 |
| [官方 Archive](https://github.com/bangumi/Archive) | 出场与明确角色关系，是冻结快照 |
| [关系定义](https://github.com/bangumi/common/blob/master/person_relations.yml) | 类型和方向，不擅自细化宽泛标签 |
| 本地声明 | 自建实体/关系与字段覆盖，单独标注、不冒充来源 |

优先读取主动保存 SQL、复用有效本地图资料、缺项在线补充。公共名册完整性与新鲜度分开，数据库更新时间不代替来源时间。

固定索引包含 451,258 条出场、95,129 条 crt、34,516 条 prsn；48,390 个角色映射条目中 10,490 个有可投影关联。条目含非动画，不能当动画覆盖率；254,305 条投影原始记录含逆向重复，不能当去重剧情边。

## 事实边界

共同出场不推导朋友/同伴/亲属。剧情保留原始类型与记录、链接、版本、方向、剧透和结束标记，逆向按共享字典规范化，重复合并不丢隐藏标记。

Archive 是角色全局关联，双方在本作出场不证明关系在本季发生；严格分季需独立依据。VERIFIED 代表类型可识别、记录可追溯，不等于人工剧情审核。

状态为 NOT_FETCHED、NOT_IN_ARCHIVE、FAILED、PARTIAL、EMPTY、VERIFIED。EMPTY 只代表当前映射没有可用事实，不说明作品没有人物关系。来源身份不按姓名合并，配音与剧情语义分开。
