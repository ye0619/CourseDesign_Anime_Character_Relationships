# 外部数据源可行性核验（2026-10-21）

本记录区分浏览器实际验证、可用接口与接入范围。网页可访问不直接等同于可复制其数据库。

| 来源 | 实际核验 | 本轮处理 |
|---|---|---|
| [FandomGraph《化物语》](https://fandomgraph.com/anime/bakemonogatari) | 浏览器可用；页面显示37角色、572关系。网络请求读取同站`/data/anime/bakemonogatari/graph.json`，包含work、relationTypes、communities、nodes、edges | 技术上可做字段转换；该文件是页面内部资产，没有核实到稳定公共API承诺或批量转载许可。只参考交互，未镜像其关系库或图片 |
| [FandomGraph条款](https://fandomgraph.com/terms) | 页面标注条款更新于2026-09-24；允许浏览、分享链接等，并说明关系注释由其编辑发布、内容可能变动 | 当前不将“能请求JSON”解释成已取得公开再分发授权；项目使用自身资料和证据模型 |
| [萌娘百科API](https://zh.moegirl.org.cn/api.php) | 浏览器实际执行`action=query&prop=info`，取得后藤一里等4页的pageid/lastrevid；请求revisions返回HTTP200，但JSON错误为`action-notallowed / Unauthorized API call` | 页面信息能力可用；不能根据HTTP200声称正文API可用。自动正文/模板关系抽取暂缓 |
| [萌娘百科后藤一里](https://zh.moegirl.org.cn/后藤一里) | 公开页面可读，核对原名、所属作品、所属团体；页面修订8606350 | 仅摘录一条明确成员事实，并记录人工匹配、版本、原页及署名；其余3个映射为CANDIDATE，不自动合并 |
| [ACDB API入口](https://www.animecharactersdatabase.com/api.php)及[公开工具](https://www.animecharactersdatabase.com/api_series_characters.php) | 文档列出character_id/character_q/anime_id/anime_q等查询；站点自带konata、attack示例返回结构化JSON | 可作为角色身份与作品归属候选。已核验示例没有提供可直接用于本项目的剧情关系/世界观断言，不伪造能力 |
| [ACDB下载接口](https://www.animecharactersdatabase.com/api_dumps.php) | 页面提示需要API key | 与上述匿名工具分开判断；未注册账号、申请key或批量下载 |
| [ACDB数据库下载](https://www.animecharactersdatabase.com/databasedumps.php) | 公开页列Characters/Titles/Assignments及数据许可说明 | 未把数据许可延伸为图片授权，也未把作品归属表当成剧情关系表 |

## 参考交互与实际改造

FandomGraph已观察到角色查找、多个布局、阵营排列、关系文字开关、选中线条与隔离网络、名册和资料表。角色图片使用cover样式；本次没有证据证明它使用自动动漫人脸检测。

项目独立实现节点/标签避让、选中关系全文区域、头肩启发式取景与本机调整、世界观范围切换、组织筛选、名册、路径高亮和证据详情。保留现有视觉风格和图谱组件。

## 数据与身份样本

身份配置位于`backend/src/main/resources/identity/worlds.json`，经启动器写入MySQL `external_identity`：

- `character:bangumi:87968`与萌娘百科404558完成原名/作品/角色资料人工核对，状态REVIEWED。
- 虹夏、凉、郁代的第二来源仅核对页面信息与同作关联，状态CANDIDATE；不用于自动归并。
- 关系样本为后藤一里属于结束乐队，范围GLOBAL；在Neo4j中以独立Evidence保存，不升级成“动画当前季已发生的剧情”。

萌娘百科样本为对原页事实的人工规范化摘录，署名“萌娘百科作者”，提供原页及修订号，遵循其[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)条件。适用范围仅为该数据摘录；后续分发需保留非商业、署名与相同方式共享说明，代码本身不因此改写许可。没有复制原站图片或大段正文。

## 当前限制

2026-10-22已完成萌娘百科3部作品×10角色的页面元信息抽样，查到26个标题候选（不等于身份审核），其中17个已有本地档案。候选文件预览、逐条登记/暂停与TITLE_ONLY审核限制已交付；没有自动抽取正文或自动审核。ACDB本机新查询出现ECONNRESET/503，未完成其覆盖抽样，FandomGraph仍仅作参考。逐条数据、版权元信息及验证范围见[10.22覆盖报告](外站覆盖抽样10.22.md)。
