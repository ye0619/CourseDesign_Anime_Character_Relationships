# 演示与运行说明

同步日期：2026-10-24。已验证本机运行与同机恢复；异机、空库应用启动和容器运行尚待验收。

## 首次配置与启停

准备 JDK（本机 23，编译目标 21）、Node >=24.15.0 且 <25、MySQL 安装目录。脚本准备便携 Neo4j 和专用运行时，首次下载需要网络；版本见[技术基线](技术基线.md)。

```powershell
# 只在没有 .env 时初始化；已有配置不要覆盖
.\scripts\Initialize-Local.ps1
Push-Location frontend
npm ci
Pop-Location
.\Start-Project.cmd -JavaHome 'C:\Program Files\Java\jdk-23' -MySqlHome 'D:\Tools\mysql-9.3.0-winx64'
.\Stop-Project.cmd
```

默认前端 5173、后端 8080、MySQL 3307、Neo4j HTTP 7474/Bolt 7687，绑定回环地址。本机 MySQL 使用 `.local/mysql` 专用目录，Java 选择只作用项目进程；停止应用默认保留两库。配置字段见[模板](../.env.example)。

`/api/v1/health/live` 检查进程，`/api/v1/health/ready` 检查两库。首次启动须完成迁移，页面能打开不代表数据库就绪。日志、进程及凭据保存在 `.local`；环境诊断为 `scripts/Check-Environment.ps1`、`scripts/Verify-Readiness.ps1`。

## 来源索引与探索范围

没有索引仍能浏览作品与角色，关系显示缺资料。使用官方 ZIP 和对应官方散列构建：

```powershell
python scripts/Build-BangumiArchiveIndex.py data/raw/bangumi/archive/dump-2026-10-13.210353Z.zip --sha256 19d12d42502fefeb4a2b14561cc978986a554320b06ca4bbf454d1830b101f90
```

该散列仅适用于这个固定样本。其他归档必须使用自身官方散列。默认 `data/index/bangumi`，后端目录中的相对配置为 `../data/index/bangumi`，可设置 BANGUMI_ARCHIVE_INDEX 绝对路径。见[来源说明](数据来源及角色关系获取说明.md)。

详情显式保存/更新，须等任务结束；联系页面还需主动更新探索范围。查询不递归联网。媒体仍可能需要外站，保存元数据不等于完整离线包。

## 容器数据库

`compose.yaml` 仅包含数据库。配置 `.env` 后执行 `docker compose up -d`，等健康检查后运行 `scripts/Start-Project.ps1 -SkipDatabases`。不要与便携两库同时占同端口。当前仅完成 Compose 静态检查。

## 检查与交付

```powershell
.\scripts\Test-Project.ps1 -JavaHome 'C:\Program Files\Java\jdk-23'
.\scripts\Test-Project.ps1 -JavaHome 'C:\Program Files\Java\jdk-23' -DatabaseIntegration
.\scripts\Build-Delivery.ps1 -JavaHome 'C:\Program Files\Java\jdk-23' -BuildOnly
```

检查包括后端、契约、文档、部署静态、辅助脚本、前端测试、类型和构建。显式数据库场景需要已有样本，会按受限范围创建清理测试记录，不等于空库部署。

Build-Delivery 生成 JAR 与前端产物并校验签名；`scripts/Seal-Delivery.ps1` 封存，`scripts/Verify-Delivery.ps1` 检验完整性。源码/脚本变化后必须重跑，旧检查不能封存新代码。Release 使用 `Start-Project.ps1 -Mode Release`。

交付包含当前源码、测试夹具、脚本、文档、配置模板、公开 JSON 样本与构建，不包含私人环境、两库目录、依赖、原始归档、索引、工具与清理备份。

## 专项工具与影响

| 工具 | 用途 |
|---|---|
| Verify-UnifiedWorks.ps1 | 实际保存/更新公开作品 373267，保留正常数据 |
| Verify-LocalGraph.ps1 | 本地编辑、恢复及来源刷新保护 |

脚本均位于 `scripts`。其他 Verify/Browser 工具是专项回归，需按各自参数与样本运行，不是任意环境的统一验收入口。

工作区与角色修改各自支持 JSON/自动备份；全库恢复比较行数、校验与图定义，属于同机独立恢复，不是异机应用验收。`.local/document-cleanup-*` 是本次文件整理前备份，不是数据库备份。
